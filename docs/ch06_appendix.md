# 第 6 章 附录

## 6.1 官方考核结构

理论考试共 60 题，其中单项选择题 30 道、多项选择题 10 道、判断题 20 道。

| 考核模块 | 占比 | 60 题中约 |
|---|---|---|
| 人工智能基础理论 | 30% | 18 题 |
| 国产操作系统技术基础 | 20% | 12 题 |
| 国产软件技术基础 | 20% | 12 题 |
| 智能体技术基础 | 20% | 12 题 |
| 国产硬件技术基础 | 10% | 6 题 |

初赛只包含理论题，省赛包含理论题和实操题。

## 6.2 高频考点分布

以下考点在两套模拟卷中出现 2 次及以上，属于反复考核的内容：

- 异构计算与加速器定位：GPU 并行特征、NPU 专用加速、异构协同
- 兼容性层次：ISA、API、ABI、运行库、依赖
- 跨架构迁移：二进制无法运行的原因、重新编译
- 故障排查：Permission denied、文件系统空间、依赖冲突、网络跨网段
- Agent 闭环：观察结果进入下一步决策、错误累积
- 工具调用：Schema、参数校验、失败处理、副作用
- 提示注入：外部内容携带恶意指令、人工确认
- 多 Agent：角色分工、通信与协调开销
- systemd：status、enable、reload、restart
- 混合精度与量化：FP16 减半、INT8 提速、精度损失
- 上下文窗口与长期记忆：Token 范围、外部持久化
- 监督学习与标签、梯度与学习率
- RAG 与微调的区别、推理时检索
- 中间件：通用能力、消息队列削峰与可靠处理
- NoSQL 与键值模型
- 目录执行权限与 umask

## 6.3 判断题陷阱句式

判断题的错误项普遍使用绝对化表述，出现以下句式时优先考虑判断为错误：

- 只要……就……
- 一定 / 必定 / 必然
- 唯一 / 只
- 所有 / 全部 / 一切
- 完全 / 彻底 / 永远
- 无需……（省略必要环节）

真题示例对应的绝对化表述：只要应用能启动就无兼容问题、增加 Agent 数量一定能线性提高质量、设备能识别就完成兼容验证、只比较数据条数即可迁移、有聊天窗口就具备完整 Agent 能力、跨架构迁移只改文件名即可、只要有工具描述就无需校验参数、提示注入只存在于用户直接输入、索引只加快读取无额外成本。

正向判断的题目通常描述机制事实，例如：观察结果指导下一步决策、长期记忆依赖外部持久化、量化降低资源但损失精度、API 兼容不保证 ABI 兼容。

## 6.4 易混概念对照

### 精度格式

| 格式 | 字节数 | 用途 |
|---|---|---|
| FP32 | 4 字节 | 训练基准精度 |
| FP16 | 2 字节 | 混合精度计算，显存减半、吞吐翻倍 |
| BF16 | 2 字节 | 数值范围大，训练稳定 |
| INT8 | 1 字节 | 推理量化，吞吐约 4 倍提升 |

### 采样策略

| 策略 | 机制 |
|---|---|
| 贪心 | 每步取概率最高的 Token |
| Top-k | 固定保留前 K 个候选 |
| Top-p | 按累计概率阈值动态选取候选 |
| 温度 | 缩放概率分布控制随机性 |

### 注意力变体

| 变体 | 机制 | 特点 |
|---|---|---|
| MHA | 每头独立 QKV | 表达力强，计算开销大 |
| MQA | 多头共享同一组 K、V | 减少 KV Cache 占用 |
| GQA | 若干头共享 KV | MHA 与 MQA 的折中 |
| MLA | 压缩 KV 表示 | 大幅降低推理成本，DeepSeek 采用 |
| FlashAttention | 分块计算、减少显存读写 | 加速注意力运算 |

### L1 与 L2 正则

| 正则 | 效果 | 机制 |
|---|---|---|
| L1 | 权重稀疏（部分归零） | 零点附近梯度恒定，推动精确归零 |
| L2 | 权重整体变小（不归零） | 梯度随权重线性缩小 |

### 信号

| 信号 | 行为 |
|---|---|
| SIGTERM | 请求可控终止，进程可捕获处理 |
| SIGKILL | 内核强制终止，不可捕获 |

### 链接类型

| 类型 | 机制 | 特点 |
|---|---|---|
| 硬链接 | 共享同一 inode | 不能跨文件系统、不能指向目录 |
| 软链接 | 指向路径的特殊文件 | 可跨文件系统、可指向目录，目标被删则失效 |

### RAID 级别

| 级别 | 机制 | 特点 |
|---|---|---|
| RAID0 | 条带化 | 提升性能，无冗余 |
| RAID1 | 镜像 | 提供冗余，容量减半 |
| RAID5 | 奇偶校验 | 兼顾性能与冗余，单盘故障可重建 |

### 学习范式

| 范式 | 数据 | 目标 |
|---|---|---|
| 监督学习 | 带标签 | 学习映射 |
| 无监督学习 | 无标签 | 发现结构 |
| 强化学习 | 环境奖励 | 学习策略 |

### RAG 与微调

| 方式 | 机制 | 知识更新 |
|---|---|---|
| RAG | 推理时检索外部知识注入上下文 | 无需修改模型参数 |
| 微调 | 用数据更新模型参数 | 修改模型参数 |

### 记忆类型

| 类型 | 存储位置 | 范围 |
|---|---|---|
| 短期记忆 | 上下文窗口 | 一次会话，容量有限 |
| 长期记忆 | 外部持久化存储 | 跨会话，需时效性与相关性管理 |

### 并行策略

| 策略 | 切分 | 通信 |
|---|---|---|
| 数据并行 | 数据批次 | 梯度同步，量大 |
| 模型并行 | 模型层 | 中等 |
| 流水线并行 | 层分段 | 开销小 |
| 张量并行 | 单层参数 | 频率极高 |

### 液冷分类

| 类型 | 接触方式 | 特点 |
|---|---|---|
| 直接接触式 | 冷却液接触芯片 | 效率高，要求绝缘 |
| 冷板液冷 | 经冷板导热 | 安全，兼容性好 |

### 冷板材料

| 材料 | 优点 | 限制 |
|---|---|---|
| 铜 | 导热高、耐腐蚀 | 成本高、密度大 |
| 铝 | 质轻、成本低 | 易电偶腐蚀，限全铝回路 |

## 6.6 排障思路速查

| 故障现象 | 排查重点 |
|---|---|
| Permission denied | 运行用户、目标文件或目录权限 |
| 文件系统空间不足 | 大文件、日志、临时文件、被删除仍占用的文件 |
| 安装依赖冲突 | 依赖链、软件源一致性、包索引 |
| 跨架构启动失败 | ISA、ABI、运行库、目标架构构建 |
| 跨网段访问失败 | 默认网关、路由 |
| 高 CPU | 进程 PID 与命令、日志、占用持续性、业务关联 |
| 新设备不可识别 | 对应驱动支持 |
| 服务仅本机可访问 | 监听地址是否绑定回环接口 |
