# 第 1 章 人工智能基础理论

考核占比 30%，为五模块中占比最高。内容从经典机器学习延伸到大模型工程。

## 1.1 机器学习基础

本节回答四个递进问题：有哪些学习范式与算法、数据要如何处理与评估、神经网络如何学习、模型如何避免过拟合并选型。

### 学习范式

**解决什么问题**：机器学习不靠显式规则编程，必须靠"数据 + 学习目标"驱动；范式不同，数据形式和学习目标就不同。

| 范式 | 数据形式 | 学习目标 | 典型任务 |
|---|---|---|---|
| 监督学习 | 输入样本加对应标签 | 学习输入到目标的映射 | 分类、回归 |
| 无监督学习 | 无标签数据 | 从数据中发现结构 | 聚类、降维 |
| 强化学习 | 环境交互反馈与奖励 | 学习最优策略 | 游戏、机器人控制 |

- 监督学习的训练数据必须包含目标标签，例如带"垃圾邮件/正常邮件"标签的历史邮件——标签提供"正确答案"，模型据此比对输出并修正
- 无监督学习从无标签数据中自动发现分组结构——没有标签，只能从数据分布本身找规律
- 强化学习根据环境反馈和奖励调整策略，奖励信号替代标签——没有现成答案，靠试错后的反馈学习

### **监督学习**
### 线性回归与逻辑回归

- 线性回归拟合连续值，模型为特征的线性组合，用梯度下降优化 MSE
- 逻辑回归输出经过 Sigmoid 映射的概率值，用于二分类
- 逻辑回归本质仍是线性模型，靠非线性激活输出概率
- 二者是最简单的监督模型，也是理解神经网络（多层线性组合加激活）的起点

### KNN 与特征缩放

KNN 是惰性算法，新样本到来时计算其与训练集样本的距离，取最近的 K 个样本按多数投票决定类别。

- 距离计算对每个特征维度同等加权
- 特征取值范围差异大时，大尺度特征在距离计算中占主导地位
- 使用 KNN 前需对特征做缩放，把各维度拉回相近量级
- 特征缩放本质是数据预处理（详见下节"数据标准化与归一化"），KNN、SVM 这类基于距离的算法尤其依赖它

### 决策树与集成学习

- 决策树按特征条件逐层划分样本，可解释性强，容易过拟合
- 随机森林由多棵决策树组成，每棵树用随机子集训练，投票输出结果，降低过拟合——多棵树的结果平均化，能摊平单棵的过拟合（降方差）
- 梯度提升树 GBDT 逐棵树拟合前序残差，代表有 XGBoost——拟合残差本质是沿"损失下降方向"做梯度下降，只是用树去拟合这个方向
- 集成学习把多个弱模型组合成强模型

### 支持向量机与朴素贝叶斯

**解决什么问题**：SVM 从"几何间隔"出发找最优分类边界，朴素贝叶斯从"概率计算"出发按后验概率定类别。前者擅长高维小样本，后者以简单高效著称。

**SVM：用"最大间隔"找最稳的分界线**

- SVM 寻找能把两类样本分开、且到两侧最近样本距离最大的超平面，这个距离称为间隔
- 为什么选最大间隔：能分开两类的线有无数条，间隔越大，数据点即使有轻微扰动也不易被分错，对新样本泛化更好
- 决定超平面的只有间隔边界上少数样本，称为支持向量——超平面只受这些"最靠边"样本约束，其余样本移动只要不越界都不影响结果，模型因此稀疏，只"记住"关键样本
- 最大化间隔等价于最小化 ‖w‖²，是凸二次规划问题——凸问题只有全局最优解，不会陷入局部最优，是 SVM 相对早期神经网络的经典优势
- 软间隔解决带噪声数据：允许少量样本越过间隔边界，用惩罚参数 C 平衡"分类正确"与"间隔大小"，C 大偏向严格分类（易过拟合），C 小偏向平滑
- 核技巧解决线性不可分：把数据映射到高维空间后可能线性可分，核函数直接计算高维内积、不必真的做映射，RBF 高斯核最常用（相当于无穷维特征空间）
- 适合高维小样本：模型复杂度主要由支持向量数决定而非特征维度，文本、基因等特征多样本少的数据尤其适用
- SVM 计算依赖样本间距离/内积，对特征尺度敏感，使用前需做特征标准化（呼应上文 KNN 与特征缩放）

**朴素贝叶斯：用"条件独立"把概率算到底**

- 朴素贝叶斯用贝叶斯定理计算"给定样本属于各类别"的后验概率，取最大者作为预测类别
- 贝叶斯定理：后验概率正比于先验概率乘似然——先验是该类别在数据中的占比，似然是该类别下出现这些特征的概率
- 朴素之处在于假设特征相互条件独立，使联合概率拆成各特征概率之积——为什么必须这样假设：否则要估计特征组合的联合分布，数据需求随特征数指数增长，现实中根本估不准；假设虽"朴素"，却让计算可行
- 训练只是"统计频率"：从数据中统计先验与各特征的条件概率即可，训练极快、可增量更新
- 常用于文本分类，如垃圾邮件识别、情感分析——把一篇文档看成词的出现频率组合，正好契合"词与词条件独立"的假设
- 输出的是概率值而非裸类别，天然带置信度，便于与其他系统结合

**小结**：SVM 用"间隔"刻画分类自信度，朴素贝叶斯用"概率"刻画分类置信度。二者同属监督学习（呼应"学习范式"），对特征处理的要求也印证了"数据标准化与归一化"的必要性。


### **非监督学习**
### 聚类与降维

- K-means 把样本分成 K 簇，迭代更新簇中心，样本归入最近簇
- K-means 需要预先指定簇数 K，对初始中心敏感
- PCA 主成分分析把高维数据投影到方差最大的方向上，实现降维
- 降维保留主要信息的同时降低计算量，常作为预处理步骤

### **数据处理与评估**

### 数据标准化与归一化

- 标准化 z-score 减去均值除以标准差，处理后均值归零方差为 1
- 归一化把数值映射到固定区间，例如 0 到 1
- 两种方式都把不同量纲的特征调整到更可比较的尺度
- 标准化按列处理，样本本身的值仍各不相同
- 量纲差异会干扰基于距离和梯度的学习算法（呼应 KNN、SVM 对缩放的依赖）

### 数据集划分与评估指标

- 数据划分为训练集、验证集、测试集
- 训练集用于更新参数，验证集用于调参和模型选择，测试集用于最终评估——验证集是"防过拟合的哨兵"：模型在训练集上可能学过头，只有没参与训练的数据才能真实反映泛化
- 回归评估常用 MSE、MAE
- 分类评估常用准确率、精确率、召回率、F1
- 精确率衡量预测为正类的样本中预测正确的比例
- 召回率衡量真实正类中被正确找出的比例
- F1 是精确率和召回率的调和平均——两者往往此消彼长（如"宁错报也别漏报"时看召回率），调和平均能同时惩罚两者的不足
- 混淆矩阵列出预测与真实的各种组合，是精确率和召回率的计算基础

### **神经网络及其优化**
### 神经网络基础

- 神经元对输入加权求和加偏置，经激活函数输出
- 偏置平移激活阈值，使神经元在输入为零时仍可调整激活状态
- 多层网络靠激活函数引入非线性，完全线性的多层叠加仍是线性变换——这正是从逻辑回归走向深度网络的本质区别
- 前向传播逐层计算输出，反向传播沿计算图回传梯度
- 卷积神经网络 CNN 用卷积核提取局部特征，适合图像
- 循环神经网络 RNN 按序列顺序处理，适合文本和时间序列，LSTM 缓解长序列梯度问题

### 损失函数

损失函数衡量模型预测与真实值的差距，训练过程即最小化损失。

- 回归任务常用均方误差 MSE，计算预测值与真实值差值的平方均值
- 分类任务常用交叉熵损失，衡量预测概率分布与真实分布的差异
- 损失越小，模型输出与真实值越接近
- 没有损失函数就无从量化误差，也就没有优化的方向

### 梯度下降与学习率

训练目标是让损失函数 L 取最小值。参数 θ 沿损失下降最快的方向逐步更新，更新规则为 θ ← θ − η·∇L，其中 ∇L 是损失对参数的梯度，η 是学习率。

- 梯度反映损失函数对参数变化的方向与敏感程度，指向损失上升最快的方向，负梯度即下降方向
- 为什么能收敛：损失面在一阶近似下，沿负梯度方向损失单调下降，逐步逼近极小值点
- 学习率过大时参数跨过最优点来回震荡，训练损失发散——步长超过损失面曲率允许的范围，就会"跳过"谷底
- 学习率过小则收敛缓慢
- 优化器基于梯度更新参数，SGD 每次用一个小批量估计梯度，Momentum 累积历史梯度冲量缓解震荡，Adam 自适应调整每个参数的学习率

### **控制模型过度泛化**
### 过拟合与正则化

过拟合指模型在训练集上表现好、在测试集上表现差，原因是模型记住了训练数据的噪声。

- 特征过多、模型复杂度过高、训练数据过少都会引发过拟合
- 正则化在损失函数上增加参数惩罚，L1 使权重稀疏，L2 使权重整体变小——L1 在零点附近梯度恒定，推动权重精确归零；L2 梯度随权重线性缩小，只能压小不能归零
- Dropout 在训练时随机丢弃部分神经元，防止网络过度依赖某些节点
- 早停观察验证集表现，在验证集开始变差时停止训练
- 数据增强增加训练样本多样性

### 偏差与方差

- 偏差衡量模型预测的平均偏离程度，高偏差对应欠拟合
- 方差衡量模型对训练数据变化的敏感程度，高方差对应过拟合
- 模型复杂度增加，偏差下降、方差上升，需要平衡——复杂度越高拟合能力越强（偏差降），但对训练数据的微小波动越敏感（方差升）
- 偏差与方差是"过拟合/欠拟合"的两种表现，与评估指标共同回答"模型好不好"

### 机器学习算法选择因素

- 任务类型，分类还是回归
- 数据规模与特征类型
- 可解释性要求
- 训练和推理资源

**小结**：机器学习以"范式定目标、数据作养料、网络学映射、泛化控质量"形成闭环。当模型从单层网络放大到海量文本预训练时，就演化为大语言模型——下一节从语言的基本单元讲起。

## 1.2 大语言模型原理

本节沿"语言如何被表示 → 用什么结构建模 → 怎么训练 → 如何高效推理 → 有什么能力与局限"的主线展开。

### Token 与分词

**解决什么问题**：模型不能直接处理整段文本，需要先切成最小处理单元。

Token 是文本切分后的最小处理单元。分词器把文本切分为 Token 序列，常用 BPE 字节对编码，从字符开始逐步合并高频共现片段。

- 一个中文词通常对应 1 个 Token
- 英文单词可能被拆为多个 Token
- Token 序列是模型输入输出的基本单位，上下文窗口以 Token 数量计量

**Token 是文本单元，但模型算的是向量——需要把 Token 映射成向量表示。**

### Embedding

Embedding 把 Token 映射为固定维度的稠密向量，语义相近的词向量距离更近。Embedding 既在模型内部承担输入表示，也单独用于向量检索（后者详见 1.5 节）。

- 词向量包含语义信息，语义相近的词在向量空间中接近
- 文本可编码为向量，用于相似度计算
- 稠密向量把离散符号变成连续数值，才能进入神经网络的矩阵运算

**有了向量表示，还需要能并行处理整个序列、并捕获长距离依赖的结构——Transformer。**

### Transformer 架构

Transformer 是当前大语言模型的基础架构。整体分编码器和解码器两部分，编码器理解输入，解码器生成输出，GPT 系列只使用解码器。

输入处理分两步。第一步把 Token 映射为向量得到 Token Embedding。第二步叠加位置编码，把顺序信息注入向量。注意力计算本身感知顺序，位置信息必须显式加入。

自注意力是架构核心：
- 每个 Token 的向量分别乘以三组权重矩阵，得到查询 Q、键 K、值 V
- 用当前 Token 的 Q 与序列中所有 Token 的 K 做点积得到注意力分数
- 分数除以维度平方根做缩放，经 Softmax 归一化为权重——为什么除以 √d_k：点积会随维度增大而变大，直接进 Softmax 容易落入饱和区导致梯度消失，缩放可稳定梯度
- 权重对各 Token 的 V 加权求和，得到融合全序列信息的输出

注意力让每个元素与序列中所有其他元素建立关联，权重越大关联越强，由此捕获长距离依赖。

多头注意力把 Q、K、V 投影到多个子空间并行计算，每个头关注不同表示方面，结果拼接后经线性层输出。

解码器在自注意力上增加因果掩码，每个位置只能看到自身及左侧 Token，保证生成时看不到未来信息。

每个注意力层之后接前馈网络 FFN，两层全连接加激活函数，逐位置独立作用。每层带残差连接和层归一化，残差让梯度顺畅回传，层归一化稳定训练。

**注意力本身感知不到顺序——同样的词在不同位置含义不同，必须显式注入位置信息。**

### 位置编码

- 绝对位置编码把位置信息直接加进 Token 向量，例如正弦编码
- 旋转位置编码 RoPE 通过旋转矩阵把相对位置信息编码进注意力计算，外推性好，主流模型广泛使用——因为编码的是"相对位置"而非绝对位置，序列更长时仍可外推到训练长度之外
- 位置编码服务于序列的顺序信息，与磁盘读写等存储操作无关

**结构确定后，用什么任务让模型学会语言？——自回归语言建模，再经历三阶段训练。**

### 自回归与预训练范式

- 大语言模型采用自回归生成，逐 Token 预测下一个 Token
- 预训练阶段在无标注语料上做语言建模，学习通用语言能力
- 因果语言建模只利用左侧上下文预测当前 Token，与解码器结构一致
- 掩码语言建模随机遮盖部分 Token 让其重建，BERT 采用

### 训练三阶段

1. 预训练：无标注语料自监督训练，学习通用语言能力
2. 微调：SFT 用带指令或示例的数据训练，让模型学会按指令行事
3. 对齐：RLHF 等技术让输出符合人类偏好

- 训练需要正向传播和反向传播，反向传播逐层计算梯度，计算量远超推理
- 推理只进行一次正向传播，逐个生成 Token，关注延迟和吞吐量
- RLHF 通过人类反馈的强化学习对齐模型输出与人类偏好
- 对齐确保 LLM 输出有益、无害、诚实

**模型越大、序列越长，注意力和 KV 缓存的开销越大——于是出现各种降本增效的注意力变体。**

### 注意力变体

**解决什么问题**：标准多头注意力 MHA 能力强，但每头独立的 QKV 让计算和 KV 缓存开销随规模急剧膨胀；注意力变体在不明显损失质量的前提下“省 KV、省显存、省计算”。要理解变体，先完整掌握基准 MHA。

**基准：标准多头注意力 MHA 是怎么算的**

MHA 的输入是上一层输出的隐状态矩阵 H，其中第 t 个 Token 的表示记为隐状态 h_t。

- 隐状态 $h_t$ 是什么：序列中第 t 个 Token 在某一层的向量表示，维度为 d；序列共 T 个 Token 就有 T 个 $h_t$，堆叠成矩阵 H（形状 T×d）
- $h_t$ 如何得到：Token 先经 Embedding 映射为向量、叠加位置编码，再逐层经过“注意力 + 残差 + 层归一化 + 前馈网络”迭代更新；进入当前注意力层的 $h_t$，就是上一层输出的第 t 行
- 权重矩阵是什么：每个注意力头各有一套投影矩阵 Wᵠ（h_t→q_t）、Wᴷ（h_t→k_t）、Wⱽ（h_t→v_t），以及最后的输出投影 Wᵒ
- 权重矩阵如何得到：训练开始时随机初始化（如 Xavier），随后靠反向传播与梯度下降更新；由于不同头梯度各异，训练后不同头会分化出不同的关注模式

每个头从隐状态派生 Q、K、V（这就是 $h_t$ → q/k/v 的推导链）：

- q_t = Wᵠ·h_t：第 t 个 Token 的“查询”，决定它想关注序列里的谁
- k_t = Wᴷ·h_t：第 t 个 Token 的“键”，是供其他 Token 匹配的标签
- v_t = Wⱽ·h_t：第 t 个 Token 的“值”，是被取走的内容

随后算注意力分数、归一化、加权求和：

- 分数 $s_ij = (q_i·k_j) / √d_k$，除以维度平方根防止点积过大落入 softmax 饱和区
- 经 softmax 归一化为权重 α_ij，权重对各 $v_j$ 加权求和，得到融合全序列信息的输出

多头把过程并行做 H 次（每头维度 $d_k$ = $d/H$），各头输出沿特征维拼接，再经 Wᵒ 融合回 d 维。多头让不同头关注不同方面（局部语法、远程指代、词对齐等），而 $H×d_k = d$ 使计算量与单头相当。

MHA 的代价：每头独立 QKV，KV Cache 和计算量都大——这正是变体要解决的问题。

**演进主线：主线：MHA → MQA → GQA → MLA (省 KV Cache)**

KV Cache
生成逐 Token 进行，每一步计算注意力时需要当前 Token 的 Q 与前面所有 Token 的 K、V 运算。
- KV Cache 把已生成 Token 的 K 和 V 矩阵缓存下来
- 每步只计算新 Token 的 Q，直接复用缓存的 K、V
- 避免每步重新计算之前所有 Token 的注意力，显著提升推理速度——没有缓存时，第 n 步要重算前 n−1 个 Token 的注意力，计算量随序列二次增长
- KV Cache 随序列长度线性增长，是推理显存占用的重要组成部分

- MQA 多头共享同一组 K 和 V，所有头共用，KV Cache 最小但质量损失较大
- GQA 分组查询注意力在若干头之间共享 KV，是 MHA 与 MQA 的折中，Llama 系列采用


**MLA：多头潜在注意力**

MLA 由 DeepSeek 提出，不靠“共享”而靠“压缩”：把每个 Token 的 K、V 先压成一个低维潜向量，缓存只存潜向量，算注意力时再展开。

- 压缩（缓存侧）：c_tᵏᵛ = Wᴰᴷⱽ·h_t，把 d 维隐状态压成 d_c 维，d_c 远小于所有头 KV 的总维度
- 展开（计算侧）：每个头用上投影 Wᵁᴷ、Wᵁⱽ 从 c_tᵏᵛ 还原出自己的 k_t、v_t
- 为什么能省缓存：缓存的是低维 c_tᵏᵛ 而非每头完整 KV；把 Wᵁᴷ·Wᴰᴷⱽ 合并成一个矩阵后，每一步算出的 k、v 与标准 MHA 完全等价，计算量不变、缓存却大幅变小
- 压缩不损质量的原因：KV 权重矩阵近似低秩，低维潜向量已能承载绝大部分信息（与 LoRA 同思路）
- 解耦 RoPE：位置信息不能压进共享潜向量，额外用独立“旋转键”通道承载——内容走压缩通道，位置走旋转通道，互不干扰
- 效果：DeepSeek 报告 KV Cache 减少约 93%，同等显存能支撑更长上下文、更大并发

**补充：FlashAttention**

- FlashAttention 不改结构，靠分块计算把注意力切成小块、减少显存读写，加速注意力运算

**小结**：MHA 用“多子空间”换表达能力，MQA/GQA 用“共享”换缓存，MLA 用“低秩压缩”换缓存且基本不丢质量，FlashAttention 用“分块”换速度——注意力变体的主线是“用尽量小的代价保住注意力能力”。

**模型训练完成后，在推理时展现出各种能力，也有其固有局限。**

### 上下文学习与思维链

- 上下文学习 ICL 指模型从 Prompt 中的示例学习新任务，无需更新参数
- 思维链 CoT 让模型先输出推理步骤再给出答案，提升复杂推理能力
- 思维链提示通过引导模型分步思考，改善多步数学和逻辑问题
- 上下文窗口限制可放入的示例和推理过程长度

### Scaling Laws 与涌现

- Scaling Laws 表明模型性能随参数量、数据量和计算量增加而可预测地提升，呈幂律关系
- 涌现能力指模型规模超过阈值后突然具备的新能力，例如推理和编程
- 涌现能力是规模法则的重要体现

### 幻觉与模型风险

- 幻觉指模型生成看似合理但事实错误或虚构的内容
- 幻觉源于模型对知识的模糊记忆和概率采样——模型不是在"查库"，而是按概率续写，记错或没有依据时就编造
- 提示注入可能来自用户直接输入，也可能隐藏在网页、文件等外部内容中
- 模型知识有截止日期，训练数据无法覆盖最新信息

### 上下文窗口

- 上下文窗口限制模型一次推理可直接使用的 Token 数量范围
- 超出窗口的历史信息无法参与本次生成
- GPT-4 上下文窗口为 128K Token，Gemini 可达 1M Token 以上
- 生成行为受上下文窗口、Prompt 内容、模型能力和采样参数共同影响

**小结**：大模型从语言单元出发，经 Transformer 结构与三阶段训练获得能力，也受幻觉与窗口限制。推理时模型输出的并非唯一答案，而是词表上的概率分布——如何选词，见下一节。

## 1.3 推理与采样

承接 1.2：自回归生成中，模型每一步输出的不是唯一答案，而是词表上的概率分布。本节回答"如何从概率分布中选词、如何控制生成"。

### 解码策略

模型每步输出词表上的概率分布，解码策略决定如何选取下一个 Token。

| 策略 | 机制 | 特点 |
|---|---|---|
| 贪心解码 | 每次取概率最高的 Token | 结果确定，可能重复单调 |
| 温度采样 | 按温度缩放概率分布后随机采样 | 温度低更确定，温度高更随机 |
| Top-k 采样 | 固定保留概率最高的前 K 个候选再采样 | 候选数固定 |
| Top-p 采样 | 按累计概率阈值动态选取候选集合再采样 | 候选数随分布变化 |

- Top-k 的 K 是固定值，例如保留前 50 个候选
- Top-p 从概率最高的 Token 开始累加，直到累计概率达到阈值，例如 0.9，候选集合大小每一步都可能不同
- 温度大于 1 使分布更平滑随机，小于 1 使分布更尖锐确定——机制：先对 logits 除以温度再 Softmax，高温把差距抹平（更随机），低温把差距放大（更确定）
- 贪心解码永远选最高概率，容易陷入局部最优而重复单调，采样类策略用随机性破局
- 生成行为同时受采样参数、上下文窗口、Prompt 内容和模型能力影响

### 生成控制

- 最大生成 Token 数限制输出长度
- 重复惩罚降低已出现 Token 的概率，抑制重复
- 停止符让模型在特定 Token 处结束生成

**小结**：采样决定"生成什么"。而模型能否真正落地，还取决于它的规模成本与部署优化——进入模型工程。

## 1.4 模型优化与工程

模型规模大，训练和部署成本高。本节回答"如何降本、如何落地"，主线为：训练侧降本（微调）→ 部署侧降本（量化）→ 资源度量（精度与显存）→ 部署引擎 → 多卡并行 → 架构侧降本（MoE）。

### 微调方式

- 全量微调更新全部参数，算力和显存开销大
- SFT 使用带指令或示例的监督数据微调模型
- LoRA 冻结原始权重，只训练低秩分解矩阵，参数量减少到 0.1%~1%——为什么有效：微调对权重的更新量往往是低秩的，用低秩矩阵近似即可表达大部分调整
- QLoRA 在 LoRA 基础上把基座权重量化，进一步降低显存
- PEFT 类方法大幅降低微调的显存和算力需求，适合算力受限场景

**微调降低"训练成本"；部署时还要压缩体积、加快推理——量化。**

### 量化

量化把高精度浮点权重映射到低精度整数，压缩模型体积。权重从 FP16 量化为 INT8，每个参数从 2 字节降到 1 字节，显存占用减少约一半。

- 常见量化方式有 GPTQ、AWQ、INT8、INT4
- 量化降低模型存储和推理资源需求
- INT8 推理相比 FP32 吞吐提升约 4 倍，精度影响小
- 量化越激进，精度损失越大，需要权衡——为什么损精度：低精度表示把连续浮点值离散到有限整数刻度，产生量化误差；位数越少误差越大
- 为什么更快：位宽减半，同样带宽下数据搬运量减半，计算单元单位时间可处理更多数据

### 精度与显存

- FP32 每个数占 4 字节，FP16 占 2 字节，BF16 同为 2 字节但数值范围更大
- FP16 显存占用减半、计算吞吐翻倍——位宽减半，数据量减半，吞吐随之翻倍
- 混合精度训练中权重以 FP32 存储、前向反向计算用 FP16、梯度累加用 FP32 更新
- 推理显存主要由三部分组成：模型权重、KV Cache、激活值
- 训练 70 亿参数模型通常需要 40GB 以上显存
- 大模型 FP16 显存需求参考：LLaMA2-70B 约 140GB，GPT-3 约 350GB，千亿级模型约 200GB
- 显存容量决定能装载的模型参数和数据量，显存带宽决定数据读写速率

**知道资源需求后，选择合适的推理引擎与服务方式让模型高效跑起来。**

### 推理引擎

- vLLM 采用 PagedAttention 管理 KV Cache，支持连续批处理，吞吐高
- llama.cpp 面向 CPU 和边缘设备，量化支持好
- TensorRT-LLM 在 NVIDIA GPU 上做图优化和层融合
- 推理优化手段包括批处理、KV Cache 复用、量化、层融合

**单卡装不下或太慢时，用多卡并行扩展算力与显存。**

### 并行策略

单卡装不下模型或训练太慢时，用多卡并行。

| 策略 | 切分方式 | 通信特征 | 适用场景 |
|---|---|---|---|
| 数据并行 | 每张卡持有完整模型，处理不同数据批次 | 梯度同步，通信量大 | 模型能装入单卡 |
| 模型并行 | 模型层切分到不同 GPU | 层间传输，通信中等 | 超大模型单卡放不下 |
| 流水线并行 | 按层分段由不同 GPU 处理 | 段间传递，开销较小 | 深度模型 |
| 张量并行 | 单层参数切分到多 GPU | 每层计算都跨卡通信，频率极高 | 大模型、MoE 模型 |

- 通信带宽不足会影响所有并行策略
- 数据并行通过梯度同步交换信息，通信量随模型规模增大
- 高速互联方案：InfiniBand 400G 以上为高性能首选，RoCE 100G/200G 为性价比方案
- 显存仍不足时可配合 CPU 卸载，把部分参数放到内存

**工程侧之外，模型架构本身也能降本——MoE 用稀疏激活换效率。**

### MoE 混合专家

MoE 把网络拆分为多个专家子网络，输入由门控路由分发给部分专家。

- 每次推理只激活部分专家，例如 8 个专家中激活 2 个——为什么省算力：稀疏激活让单次推理只计算少数专家，总参数量大但实际计算量小
- 总参数量大但实际计算量小，兼顾性能与效率
- 门控路由决定输入交给哪些专家，负载均衡影响训练稳定性——若路由总把输入交给同一批专家，其余专家得不到训练，需要额外均衡约束
- 代表性模型采用 MoE 架构配合 MLA 注意力机制，降低推理成本（呼应 1.2 注意力变体）

**小结**：工程化围绕"降本提速"展开。但无论模型多大多快，其知识仍停留在训练截止日期——要回答最新问题，需要注入外部知识，这正是 RAG；而 RAG 的第一步，是把文本变成向量——下一节。

## 1.5 Embedding 与向量检索基础

承接 1.4：模型知识有截止日期（见 1.2 幻觉与风险）。RAG 的做法是"在生成前检索外部知识注入上下文"，而检索的第一步就是把文本变成向量——本节讲向量化与检索。

### Embedding 模型

- Embedding 模型把文本编码为固定维度向量，例如 1024 维
- 向量空间中的距离反映语义相似度，常用余弦相似度衡量
- 高相似度说明两个文本在当前表示中更接近，单独不能证明事实内容一致
- 与 1.2 的 Embedding 区分：那里是模型内部的输入表示；这里指独立训练的检索专用模型，把整段文本编码成向量

### 向量数据库

- 向量数据库存储向量并支持相似度检索，常见有 Milvus、Chroma、FAISS
- 检索时把查询编码为向量，找出最相似的 K 个片段
- 索引结构加速检索，例如 HNSW 图索引、IVF 倒排——为什么需要索引：全库线性扫描在大规模数据下太慢，近似最近邻索引用空间结构跳过大量无关向量
- 向量检索是 RAG 的基础组件

**小结**：向量检索解决"从外部知识中按语义找相关片段"。把它接入生成流程、与 Agent 结合，就是第 4 章的 RAG。

## 1.6 多模态与语音模型【拓展】

承接 1.5 的向量空间：文本能向量化，图像、音频同样能经各自编码器映射到同一向量空间，让语言模型统一处理。

- 多模态模型可同时处理文本、图像、音频等多种数据
- 视觉语言模型支持看图问答，视频模型支持视频理解
- 语音识别模型把语音转为文本，语音合成模型把文本转为语音
- 多模态输入经各自的编码器统一到向量空间，再由语言模型融合处理
- 多模态输入同样消耗上下文窗口和显存，图片和视频的 Token 开销大于文本
