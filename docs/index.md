# 智能体应用开发实践赛 · 知识手册

基于操作系统 AI+ 理论模拟练习备考手册，覆盖官方考核五大模块。

## 官方考核结构

理论考试共 60 题：单选题 30 道、多选题 10 道、判断题 20 道。初赛只考理论，省赛理论加实操。

| 考核模块 | 占比 | 手册章节 |
|---|---|---|
| 人工智能基础理论 | 30% | [第 1 章](/ch01_ai_foundation) |
| 国产操作系统技术基础 | 20% | [第 2 章](/ch02_os_linux) |
| 国产软件技术基础 | 20% | [第 3 章](/ch03_software) |
| 智能体技术基础 | 20% | [第 4 章](/ch04_agent) |
| 国产硬件技术基础 | 10% | [第 5 章](/ch05_hardware) |

## 章节导览

- [第 1 章 人工智能基础理论](/ch01_ai_foundation) 机器学习范式与优化主线、LLM 原理、推理采样、模型工程、向量检索（RAG 基础）
- [第 2 章 国产操作系统技术基础](/ch02_os_linux) 内核与启动流程、Shell 与命令、文件权限、进程服务、存储、网络、包管理与生态适配
- [第 3 章 国产软件技术基础](/ch03_software) 数据库、中间件、兼容迁移、国产软件生态
- [第 4 章 智能体技术基础](/ch04_agent) Agent 架构闭环、工具调用、RAG、MCP、Skill、安全评测
- [第 5 章 国产硬件技术基础](/ch05_hardware) 国产 CPU、兼容层次、异构计算、GPU 与 CUDA、天数产品、液冷
- [第 6 章 附录](/ch06_appendix) 高频考点、判断题陷阱、易混对照、命令速查、排障速查
- [第 7 章 MCP 与 Agent 落地实践](/ch07_mcp_agent_practice) 可运行的 MCP 服务与 Agent 代码
- [知识网络图](/graph) 全部知识点的关系图谱，点击跳转对应章节
