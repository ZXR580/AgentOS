## 2. 技术架构体系

### 2.1 架构总览

V25 的整体架构设计思路：

- **底座**："磐石架构 + 安全架构"——保证稳定与安全。
- **延展**：应用兼容（如意玲珑、Windows 兼容、兼容模式）+ AI 能力（AIOS）。
- **目标**：从传统基础平台演进为**智能化桌面生产力平台**。

```
┌────────────────────────────────────────────────┐
│  应用层（原生应用 / Windows兼容应用 / 存量应用）      │
├────────────────────────────────────────────────┤
│  应用兼容体系：如意玲珑 · deepin-wine · 兼容模式     │
│  AI 能力：UOS AI / Agent / MCP&Skills             │
├────────────────────────────────────────────────┤
│  磐石架构：不可变系统 · 版本部署 · 快照回滚 · 只读保护  │
├────────────────────────────────────────────────┤
│  安全架构：可信启动 · 访问控制 · 签名验证 · 数据保护    │
├────────────────────────────────────────────────┤
│  硬件与固件层（多架构 CPU / 显卡 / AI 芯片）          │
└────────────────────────────────────────────────┘
```

### 2.2 磐石架构（不可变系统）

磐石架构是 V25 的**稳定性底座**，基于**不可变系统（Immutable System）设计理念**：

- **系统分层机制**：系统层与数据层分离。系统层承载基础组件（保证一致性与可控性），数据层存储用户数据与配置（升级不影响用户数据）。
- **启动管理机制**：统一启动与挂载链路，核心目录保持**只读**，简化启动流程，统一入口支撑系统恢复、部署切换、故障修复。
- **版本部署与更新机制**：基于 **OSTree 思路的版本化更新模型** + **Debian 软件生态**实现增量更新。升级=生成新版本→验证→切换，异常可回退。
- **系统快照与恢复机制**：对部署状态做快照，记录各版本运行状态，升级失败可快速回滚。
- **核心能力**：
  - **只读保护**：核心系统目录（如 `/usr`）设为只读，与用户数据分离，避免误操作/软件安装破坏系统。
  - **系统快照管理**：每次升级/部署生成独立版本，可保留多个历史版本、按需切换。
  - **无忧还原**：基于 **OverlayFS** 构建"重启即还原"运行模式，运行期修改写入叠加层，重启自动清除；支持**持久化白名单**保留必要数据。
  - **增量更新**：版本化更新 + 差异数据下载，仅更新变化内容，异常时继续用原版本。

### 2.3 智能操作系统（AIOS / AgentOS）

V25 将 AI 从"应用能力"提升为"系统基础能力"，构建 **AgentOS 能力体系**，深度集成于 DDE 桌面环境：

- **系统级 AI 服务**：统一接口对系统组件与第三方应用提供 AI 能力。
- **桌面环境智能化**：任务栏托盘、随航助手、语音助手插件等形式。
- **生产力增强**：智能问答、文档处理、写作辅助。
- **开放 AI 平台**：**AISDK** 标准化接口 + 插件机制。

**UOS AI 三大核心能力体系**：

1. **多模态交互**：划词问答、自然语言对话、截图问答、语音问答；支持多模型切换、流式输出。
2. **Agent 智能体能力**：任务理解与推理、意图解析与规划、复杂任务分解与自主执行。
3. **系统控制能力**：通过 **MCP 与 Skills** 机制实现 AI 与 OS 深度融合，可用自然语言完成应用启动、系统设置、日程管理等。

**AI 模型管理服务**：系统级模型统一存储/调度/运行；分层管理支持版本控制、增量更新与回滚；多种推理模式与资源调度策略。

### 2.4 系统安全

安全体系设计原则："**信任可验证、行为可约束、配置可管控、事件可追溯**"。

**四层安全架构**（自下而上）：

| 层级 | 职责 |
|---|---|
| 硬件层 | 可信计算基础：安全芯片、安全 CPU、TPM/TCM、UKey、FIDO |
| 内核层 | 安全启动、完整性验证、强制访问控制、内核模块保护（基于 Linux 安全框架 + 自研安全模块） |
| 系统层 | 身份认证、授权管理、安全审计、策略统一配置与集中管理 |
| 应用层 | 软件包完整性验证、数据加密、文件保护、外设安全管理 |

**核心安全能力**：

- **访问控制**：内核强制访问控制 + 传统权限模型多维判定 + 路径级文件保护，实现"访问主体 + 访问对象"双重控制。
- **软件可信验证**：覆盖安装与运行全过程的签名验证机制，统一证书体系建立信任链——"来源可信、内容完整、执行可控"。
- **数据保护**：系统级分区加密，支持口令、安全芯片、多因子认证解密。
- **系统运行保护**：安全启动（UEFI 启动信任链）、镜像完整性校验、关键模块保护、开发者模式管控、统一身份认证（口令/密钥/生物识别）。

## 3. 应用兼容体系

V25 构建**多层次应用兼容体系**，三类能力解决三类应用迁移问题：

### 3.1 如意玲珑

- 定位：统一**应用封装、分发与运行平台**，解决不同发行版系统库/依赖/运行环境差异。
- 架构：**分层解耦**——统一运行基础 + 核心组件（包管理/运行控制/权限管理/分发更新）+ 应用生态层。
- 能力：跨发行版兼容、多架构部署、沙箱安全、高效分发、应用全生命周期管理。

### 3.2 Windows 应用兼容技术

- 组成：**deepin-wine 运行环境**（Windows API 兼容）+ **统信 Windows 应用兼容引擎**（安装/运行/管理工具化）。
- 相比虚拟机的优势：无需完整运行 Windows，资源占用更低、效率更高。
- deepin-wine 特性：支持 x86、ARM 等多架构及国产处理器；与桌面深度集成（拖拽、剪贴板、外设、图形加速）。
- 兼容引擎提供 **4000+ 款经 deepin-wine 验证的应用**；在 **amd64 架构**上 wine 应用可获接近原生体验。
- 用户可直接**双击安装运行 exe**，并支持 wine 容器配置、组件依赖安装、调试诊断与自动修复。

### 3.3 兼容模式

- 适用：系统升级后，依赖旧版本系统组件/运行环境的存量应用。
- 机制：轻量化隔离 + 独立运行环境，保持依赖关系同时与宿主系统数据交互。
- 能力：环境隔离与依赖管理、自动化运行环境加载、桌面环境集成、GPU/音频/数据目录资源共享与隔离。

## 4. 系统核心能力

### 4.1 内核能力（Linux 6.6）

- **性能与调度**：CPU 调度策略优化、NUMA 场景适配、能耗感知调度；优化锁机制与系统调用路径；内存侧优化页面回收、透明大页；I/O 侧引入 **io_uring** 降低读写延迟。
- **安全与稳定**：内核随机化、控制流完整性、BPF 安全校验、可信执行；**USEC 内核安全模块**、设备与网络管控、TPM/TCM 支持；**UOSSTE** 崩溃定位机制。
- **兼容与扩展**：支持多处理器架构；文件系统支持 F2FS、tmpfs、FUSE、NFS、SMB3；网络与虚拟化增强 **eBPF、Netfilter、KVM、Hyper-V**。

### 4.2 桌面环境（DDE）

- 以 **DDE（Deepin Desktop Environment）** 为核心，基于 **QML 架构**重构。
- 核心组件：
  - **任务栏**：多窗口独立展示与快速切换，托盘与插件区优化。
  - **启动器**：应用分组、多种排序、常用与最近使用展示。
  - **通知系统**：富内容通知与快速跳转。
  - **剪贴板**：历史记录快速访问（`Super+V`）。
  - **控制中心**：系统配置与设备管理核心入口，按 QML 重构提升响应。

### 4.3 UOS AI 能力

- 系统智能交互与控制：自然语言驱动系统与应用。
- **AI 随航**：跨应用，在当前工作界面直接解释、总结、翻译、优化。
- 场景化办公：结构化写作（多参考资料 + 大纲生成长文）、长文总结、逻辑优化、多语种翻译、风格改写。
- 专属知识管家：私域知识库（本地资料统一管理与语义理解）、精准问答。
- 智能运维助手：实时指导与问题定位。
- 模型接入：**云端大模型、本地模型、私有化部署**多层级接入，"数据可用、边界可控"。

### 4.4 应用管理与分发

- **应用商店**：统一入口，收录**超 10 万款应用**，覆盖办公、开发、教育、设计等。
- 平台根据系统版本、处理器架构、设备环境**自动匹配适配版本**。
- 整合原生 Linux 应用、Windows 兼容应用及驱动资源。
- 安全：签名校验、内容检测、运行验证。

### 4.5 外设与设备管理

- **打印**：统一管理组件，支持 USB、网络协议、**Windows 共享打印**；智能驱动匹配与标准驱动加载，自动识别设备并适配驱动。
- **扫描**：统一扫描管理，支持多设备接入，输出可生成 **PDF、OFD** 等文档格式。

### 4.6 运维与系统管理

- 图形化安装、内置**备份还原**（支持系统与数据可视化管理与快速恢复）。
- **远程协助**：局域网及互联网环境下远程连接与操作。
- 系统监视、日志收集、系统修复工具。

## 7. 安装与部署

### 7.1 安装准备

1. **获取镜像**：官网下载对应架构的镜像文件（AMD64 / ARM64 / LoongArch64 / SW64）。
2. **哈希校验**：下载后先校验（下载页有"哈希验证"入口）。
3. **制作启动盘**：
   - 使用统信启动盘制作工具（UOS 预装；Windows 可从镜像解压）。
   - U 盘要求：≥8GB、建议格式化为 **FAT32**、正规 U 盘。
   - 制作会清除 U 盘数据，先备份。
4. **BIOS 引导**（仅供参考）：台式机 `Delete`、笔记本 `F2`、联想 `F1` 等，设置 U 盘为第一启动项。

### 7.2 安装流程

1. 安装引导界面：选择"**安装 UOS Desktop 25**"（默认）；也可选"试用"体验模式。
2. 选择语言（默认简体中文）→ 阅读并勾选许可协议 → **镜像校验**。
3. **选择安装方式（4 种）**：

| 方式 | 说明 |
|---|---|
| 全盘安装 | 一键自动，无需手动分区；要求磁盘 ≥64GB；自动分为"系统盘 + 数据盘" |
| 自定义安装 | 支持一键安装第二个系统（双系统） |
| 手动安装 | 自行配置分区大小、挂载点、文件系统 |
| 整机备份安装 | 通过 **uimg** 文件快速恢复系统，复用配置与数据，跳过创建账户 |

4. **可选功能**：
   - **全盘加密**：安装时对整个磁盘加密，启动需先输入解密密码（防拆盘取数）。
   - **启用系统扩容**：安装后可用 Live 工具/磁盘管理器动态调整系统分区大小。
   - **保留用户数据**：重装时勾选可保留之前的用户数据（需分区配置一致、不调整系统空间）。
5. **手动分区建议**：
   - `/boot`：系统启动分区，须是主分区中第一个分区。
   - 根分区 `/`：建议 **23GB 以上**。
   - 推荐创建 `swap` 分区，按物理内存大小设置。
   - 支持 **LVM 逻辑卷**：可将多磁盘空闲空间组合成逻辑卷组（lvm2 pv → 创建逻辑卷），但可能影响性能，非必要不建议。
6. **创建用户**：设置头像、用户名、主机名、密码（必须步骤）；系统语言、时区、键盘布局有默认值。
7. **准备安装 → 正在安装 → 安装成功**，点击"立即重启"后尽快拔出启动 U 盘。
8. **安装失败**：可扫描二维码上报，或导出错误日志到外置存储。

### 7.3 激活方式

- 在线激活：试用期激活（90 天）、输入序列号、导入激活文件（`.key`）。
- 离线激活：网络异常时扫码 → 输入离线激活码。
- 更换序列号条件：已激活且授权模式为 OPEN。

### 8.1 基本操作

| 操作 | 方式 |
|---|---|
| 登录 | 图形登录（输入用户名密码）；远程登录 `ssh 用户@IP` |
| 锁屏 | `Super+L`；自动锁屏在 电源管理 > 使用电源 设置 |
| 注销 | 任务栏关机图标或 `Ctrl+Alt+Delete`；远程 `logout` |
| 关机/重启 | 电源图标或 `Ctrl+Alt+Delete` |
| **切换启动级别** | 终端 `sudo init 3` 进字符界面；`Ctrl+Alt+F2` 切到字符行；`sudo init 5` 回图形界面 |

### 8.2 桌面

- 右键：新建文件夹/文档、压缩/解压、剪切复制、重命名、创建链接、标记信息、病毒查杀、属性。
- 排序方式：名称 / 修改时间 / 创建时间 / 大小 / 类型。
- **剪贴板**：`Super+V` 唤出，支持历史记录、拖拽保存。
- 快捷键：`Super+D` 显示桌面；`Alt+M` 打开右键菜单；`Ctrl+滚轮` 调图标大小。

### 8.3 任务栏与启动器

- 任务栏模式：**经典模式 / 居中模式**；位置可上/下/左/右。
- 应用管理：驻留/移除驻留、开机自动启动、卸载（部分系统应用不可卸载）。

### 8.4 全局搜索

- 唤出：任务栏图标或 `Shift+Space`；关闭：`Esc`。
- 分类展示：文件、文件夹、文档、应用、设置、视频、音乐、图片、Web 搜索。
- 搜索配置：路径黑名单、最佳匹配、默认搜索引擎。

### 8.5 控制中心（核心设置入口）

| 模块 | 主要内容 |
|---|---|
| 系统 | 显示（亮度/分辨率/缩放/多屏 `Super+P`）、声音、通知、时间日期、语言区域、默认程序、启动菜单、**开发者选项**（进入开发者模式可用 root/sudo）、**磐石只读保护**开关、域管理、备份还原、关于本机（版本/激活） |
| 网络 | 有线、无线（含隐藏网络）、个人热点、飞行模式、**DSL/PPPoE**、**VPN**、系统代理、网络详情（MAC/IP/网关） |
| 个性化 | 主题、外观（浅/深/自动）、桌面和任务栏、窗口效果、壁纸、屏幕保护、颜色和图标、字体字号 |
| 蓝牙和其他设备 | 蓝牙（传/收文件）、鼠标与触控板（手势）、键盘（输入法/快捷键）、触控屏、数位板 |
| 电源管理 | 性能模式（平衡/高性能/节能）、唤醒设置、关机设置、显示器关闭/待机/锁屏时间、低电量管理 |
| 账户 | 创建账户、自动登录/免密登录、密码有效期、生物认证（指纹/人脸） |
| UOS ID | 注册登录、云同步（配置同步到云端，需已激活或试用期） |
| 隐私和安全 | 应用访问摄像头、文件/文件夹权限管控 |
| 系统更新 | 检查更新、更新并重启/关机、更新设置（类型/限速/自动下载/更新提醒） |

> **开发者模式**：进入后可使用 root 权限执行 `sudo`；不可退出/撤销；系统所有账号将拥有 root 权限；进入后不再享有官方保修。

## 9. 系统关键应用

### 9.1 文件管理器

- 启动：`Super+E`。
- 视图：图标 / 列表 / 树形列表（`Ctrl+1/2/3`）；多标签页、固定标签、书签、标记信息、文件预览（空格键）。
- 搜索：`Ctrl+F`；支持全文搜索、高级搜索（范围/大小/类型/时间）。
- 批量重命名：替换文本、添加文本、自定义文本+递进数字。
- **权限管理**：属性 → 权限管理，为所有者/群组/其他用户设置权限。
- 共享：启动 smb 服务 → 共享此文件夹 → 设置共享密码；访问 `smb://IP`。
- **文件保险箱**：专属加密空间；两种加密方式——**密钥加密**（密码含大/小写字母+数字+符号且 ≥8 位）与**透明加密**（免输密码访问）。
- 文件粉碎：彻底删除不可恢复（需在设置中开启）。
- 文件角标：命令行 `gio set <文件路径> -t stringv metadata::emblems "<图标路径>"`。
- 磁盘管理：本地磁盘重命名、隐藏内置磁盘、外接磁盘挂载。

### 9.2 软件包安装器

- 是 **deb 包和 uab 包**管理工具（uab 即如意玲珑应用包）。
- 支持批量安装、版本信息识别。

### 9.3 终端

- 启动：`Ctrl+Alt+T`。
- 复制/粘贴：`Ctrl+Shift+C` / `Ctrl+Shift+V`（不同于普通应用的 Ctrl+C/V）。
- **雷神模式**：`Alt+F2` 唤出/隐藏下拉终端。
- 窗口：新建窗口、全屏（`F11`）、**纵向分屏 `Ctrl+Shift+J` / 横向分屏 `Ctrl+Shift+H`**。
- 标签页：新建 `Ctrl+Shift+T`、切换 `Ctrl+Tab`、`Ctrl+Shift+1~9` 选对应标签、重命名 `F2`。
- **远程管理**：添加服务器（服务器名/地址/用户名/密码），一键登录；支持分组。
- 编码调整：解决乱码。

### 9.4 安全中心

- **系统体检**：一键体检、一键修复。
- **病毒查杀**：全盘 / 快速 / 自定义扫描；定时扫描；USB 扫描；实时防护；隔离区 / 信任区 / 白名单；病毒库在线与离线更新（`.zip` 病毒库文件）。
- **防火墙**：默认关闭；公共网络 / 专用网络 / 自定义规则（程序服务、策略、方向、协议、端口/IP）。
- **垃圾清理**：系统垃圾、应用垃圾、痕迹信息、Cookies。
- **安全工具**：
  - 登录安全：密码安全等级（高/中/低）、密码到期提醒。
  - 自启动应用管理。
  - **应用安全**：切换"仅允许签名应用"（统信商店应用/企业自研应用/第三方签名应用）或"允许任意应用"。
  - **内核模块防卸载**：保护 .ko 内核模块。
  - **进程防杀死**：保护可执行文件/应用进程。
  - **联网控制**：询问 / 允许 / 禁止。
  - **流量监控**：当前联网、流量排名。
  - **网络检测**：公网/内网环境配置，一键检测定位异常。
  - **外设管理**：USB 接口、USB 存储设备（读写/只读/禁止）、USB 打印机、摄像头、蓝牙设备的管控；设备管控黑白名单（设备级策略优先级高于接口级）。
  - **文件审计**：监控用户数据盘与移动存储设备的删除操作。
  - **文件保护**：受保护文件仅读执行权限，禁止修改/删除。

### 9.5 应用商店

- 登录：微信扫码 / 手机验证码 / 邮箱 / 账号密码（UOS ID）。
- 栏目：热门推荐、装机必备（可一键批量安装）、全部分类。
- 排序：下载量、更新时间、评分；一键下载自动安装。

### 9.6 其他常用应用

- 备份还原、远程协助（IP/识别码，控制/观察模式，聊天/语音/截图/录屏/文件传输）、截图录屏、浏览器、邮箱、文档查看器、归档管理器、启动盘制作工具、打印管理器、扫描管理器、办公云盘、服务与支持。

## 10. 系统管理

### 10.1 系统监视器

- 硬件监控：处理器、内存、网络、磁盘（实时负载/占用/速度）。
- 进程管理：搜索进程、排序（CPU/内存/进程号/优先级等）、结束进程/强制结束、暂停/继续、改变优先级、查看进程路径与属性。
- 系统服务管理：启动/停止/重新启动服务、设置启动方式（自动/手动）、刷新。
- 预警：系统防护（CPU/内存占用阈值 → 预警通知）。

### 10.2 设备管理器

- 硬件信息：概况、处理器、主板、内存、显示适配器、音频适配器、存储设备、网络适配器、鼠标、键盘、显示设备。
- 操作：复制、刷新（`F5`）、导出（txt/docx/xls/html）、禁用/启用、**更新驱动**（支持 deb 与 ko 驱动文件；失败自动回滚）、卸载驱动。
- 唤起电脑：鼠标/键盘/网卡 **Wake On LAN** 设置。

### 10.3 磁盘管理器

- 磁盘信息、健康状态、新建分区表（GPT / MSDOS）。
- **健康管理**：硬盘健康检测、分区表错误检测、坏道检测与修复（无坏道/尝试修复）。
- **分区操作**：新建分区（支持 **AES/SM4 文件加密**；MSDOS 最多 4 个主分区，GPT 最多 128 个）、空间调整（扩展/压缩，FAT32 不支持压缩）、擦除（快速/安全/高级三种标准）、挂载/卸载、删除。
- **逻辑卷管理**：创建逻辑卷组（`vg01`、`vg02`…），将多磁盘分区化零为整。

### 10.4 日志收集工具

- 按日志类型、日期查看；由于系统版本或架构不同，可查看的日志类型可能有所差异。

### 12.2 关键命令行

| 命令 | 说明 |
|---|---|

| `ssh 用户@IP` | 远程登录 |

### 12.3 易混淆 / 易错点

1. **终端复制粘贴**是 `Ctrl+Shift+C/V`，不是 `Ctrl+C/V`（后者是中断/粘贴）。
2. **开发者模式**进入后不可退出、所有账号获 root 权限、不享官方保修。
3. **磐石只读保护**默认开启，`/usr` 等系统目录只读；关闭有系统损坏高风险。
4. **文件保险箱**密钥加密密码要求：含大/小写字母+数字+符号、≥8 位。
5. **全盘加密**启动需先输解密密码；**全盘安装**要求磁盘 ≥64GB。
6. **手动分区**：`/boot` 须是主分区第一个；根分区建议 ≥23GB；推荐建 swap。
7. **UOS 支持架构**：AMD64/ARM64/LoongArch/SW64（Intel/AMD 属 AMD64 架构）。
8. **应用商店**超 10 万应用，按架构自动匹配版本；**软件包安装器**管理 deb/uab 包。
9. **V25 内核 6.6**、基于 **Debian 生态**、桌面为 **DDE**。
10. **安全中心防火墙默认关闭**；外设管理设备级策略优先级高于接口级策略。
